# Roadmap

This roadmap lists reviewable project needs, not promised delivery dates.

## Near term

- Add WebP and JPEG dimension parsing for mask packs; SVG and PNG dimensions are already enforced.
- Add an accessible keyboard-first alternative to range sliders.
- Add integration tests for Redis command failures and HTTP status mapping.
- Document one community-created pack end to end.

## Later, if usage supports it

- Add a second storage adapter based on a real adopter request.
- Evaluate extracting `src/lib/core` as a package only after two independent applications need it.
- Add content-pack schema export for editor tooling.

## Non-goals

- Bundling copyrighted character or franchise assets.
- Adding AI gameplay solely for program applications.
- Building accounts, payments, or social feeds into the engine core.
